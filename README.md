This Citizen Engagement System MVP was developed using TypeScript to ensure robust type safety and maintainability. I focused on building a scalable and user-friendly platform that enables complaint submission, intelligent categorization, and status tracking. The system features a streamlined citizen interface and a simple admin dashboard for agency responses, laying the foundation for analytics integration. I integrated a basic rules-based router to direct complaints to the correct agency based on category. On the frontend, I used React with TypeScript, focusing on a responsive, user-friendly form and a citizen dashboard to track ticket status. For the admin panel, I provided an interface for viewing and responding to complaints. TypeScript improved scalability, reduced runtime errors, and enhanced collaboration across components.
